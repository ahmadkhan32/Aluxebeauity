## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open browser at
http://localhost:3000
```

---

## 📦 Build & Deploy

```bash
# Build for production
npm run build

# Start production server locally
npm start
```

### Deploy to Vercel
1. Push to GitHub: `https://github.com/ahmadkhan32/Aluxebeauity.git`
2. Import project at [vercel.com](https://vercel.com)
3. Set environment variables from `.env.local`
4. Deploy! 🚀
